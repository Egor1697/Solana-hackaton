# Solana-hackaton
AgroFraction — это платформа на базе Solana для токенизации реальных активов с возможностью фракционного (дробного) владения. Мы превращаем дорогой объект в 1000 мелких цифровых токенов. Это позволяет любому желающему купить даже 0.1% актива и получать пропорциональный доход от его использования (например, аренды)
